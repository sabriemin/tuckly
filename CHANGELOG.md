# Changelog

## 0.1.1

- About page shows the developer with a link to their GitHub profile
- The guided tour opens on the first start after installing, also when settings already exist

## 0.1.0

First release.

- Desktop cards that group items without moving the files; placed items are hidden on the desktop and
  restored when Tuckly quits
- Folder cards
- Four card styles (flat, frosted glass, liquid glass, Material), dark and light mode, preset and custom
  colors, accent color, opacity, saturation, brightness, corner radius, border and font settings
- Per-card color, opacity, icon size, sort order and locks for position, size and content
- Categories and one-click organizing of loose desktop items, with undo
- Control panel with settings search, a built-in guide and a guided tour
- Explorer right-click entries: "New Tuckly card" and "Add to Tuckly card"
- Optional notification-count badges on app shortcuts
- Settings export, import and reset
- Turkish, English, German, Spanish, French and Russian
- Update check against GitHub releases, installer and uninstaller
