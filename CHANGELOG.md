# Changelog

## 0.3.0

- Note cards have their own settings: text size, sticky-note paper colors and word wrap
- Notes support to-do items with a done/total counter in the title, bullets, headings, bold, italic and strikethrough
- Web addresses in notes are highlighted and open with Ctrl+click
- Note reminders: a Windows notification at the chosen time brings the note to the front
- Copy a note to the clipboard or save it as a .txt or .md file
- Quick launcher (Ctrl+Alt+F): type to find and open any item in any card, or jump to a note
- Optional: hide all cards while a full-screen game, presentation or video is running
- Card schedules: show a card only on chosen days and hours
- Folder cards can be browsed: double-click a subfolder to enter it, with a back button and path bar
- Recent files card that lists the files most recently opened in Windows
- Card templates (Work, Gaming, Design, Student) that add a ready-made set of cards
- Clock, calendar and weather cards; weather comes from Open-Meteo for a city you enter
- Clipboard card that keeps the last 20 copied texts in memory only
- Web links card with site icons; drag an address from the browser or add it in the settings
- Select several cards with Ctrl+click to move them together, align them or give them the same size
- Card settings have a separate Lock tab again; Behavior holds open-on-hover, schedule and tabs

## 0.2.0

- Double-click an empty spot on the desktop, or press Ctrl+Alt+H, to hide and show all cards
- Global shortcuts: Ctrl+Alt+N for a new card, Ctrl+Alt+T for the settings
- Search inside crowded cards from the magnifier in the card title
- Optional emoji in front of a card title
- Moving cards snap to screen edges and to each other (hold Alt to move freely)
- Cards can open on hover: they stay as a title and expand under the pointer
- Note cards that hold free text instead of files
- Accent color can follow the desktop wallpaper
- Named layouts: save the position, size and content of all cards and restore them later
- Card positions are remembered per monitor setup and restored when a monitor is connected or removed
- Tabbed cards: combine several cards in one place and switch between them with tabs
- Name rules: items whose name contains a chosen word go to that card when organizing

## 0.1.3

- The drop highlight around a card no longer stays on after a drag leaves the card or is cancelled

## 0.1.2

- Docks and taskbar tools that read the window class icon (for example Nectar) now show the Tuckly logo

## 0.1.1

- About page shows the developer with a link to their GitHub profile
- The guided tour opens on the first start after installing, also when settings already exist

## 0.1.0

First release.

- Desktop cards that group items without moving the files; placed items are hidden on the desktop and
  restored when Tuckly quits
- Folder cards
- Four card styles (flat, frosted glass, liquid glass, Material), dark and light mode, preset and custom
  colors, accent color, opacity, saturation, brightness, corner radius, border and font settings
- Per-card color, opacity, icon size, sort order and locks for position, size and content
- Categories and one-click organizing of loose desktop items, with undo
- Control panel with settings search, a built-in guide and a guided tour
- Explorer right-click entries: "New Tuckly card" and "Add to Tuckly card"
- Optional notification-count badges on app shortcuts
- Settings export, import and reset
- Turkish, English, German, Spanish, French and Russian
- Update check against GitHub releases, installer and uninstaller
